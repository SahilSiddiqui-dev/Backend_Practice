## Getting started

### 1) Clone the repository

```bash
git clone <your-repo-url>
cd Backend_Practice
```

### 2) Run any project

Move into the project folder you want to run, install dependencies, then start it.

```bash
npm install
npm run dev
```

If `dev` is not available in a backend project, use:

```bash
npm start
```
